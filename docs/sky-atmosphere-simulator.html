Scene values & implementation notes

The base Oklch generator is unchanged. The atmosphere is a deterministic Canvas 2D prototype: procedural cloud masks, a geometry-gated sun, separate twilight glow, and a visibility veil.

Cloud shapes are illustrative, not measured. Sunlight thresholds are artistic controls. The existing gradient's night brightness is preserved for comparison; night palette calibration remains separate.
