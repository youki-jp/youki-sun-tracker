# Codex Project Notes

These files are the project-local operating reference for Codex and other coding agents.

Read them in this order:

1. [`project-context.md`](project-context.md) for the architecture and current implementation state.
2. [`standards.md`](standards.md) for coding, documentation, testing, and Git expectations.
3. [`references.md`](references.md) for canonical files, commands, API contracts, and external documentation.

The human-facing snapshot is [`../docs/current-state.md`](../docs/current-state.md). The root [`../CLAUDE.md`](../CLAUDE.md) is the compact entry point for Claude.

## Maintenance Rule

Update these notes when a structural decision changes. Do not update them for every small UI copy or styling change. Keep implementation truth in source code and use these files to explain boundaries, conventions, and known gaps.
